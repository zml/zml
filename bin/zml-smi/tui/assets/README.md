# ZML logo

`zml-logo-glow.svg` is the original asset from
[zml.ai](https://zml.ai/img/zml-logo-glow.svg).

zml-smi embeds this SVG directly. At startup, LunaSVG renders it to transparent
RGBA pixels for the Kitty graphics protocol. No PNG logo is stored or generated.
Terminals without image support keep using the text logo.
